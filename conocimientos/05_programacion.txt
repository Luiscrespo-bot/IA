##############################################################
1. ¿QUÉ ES PROGRAMAR?
##############################################################
Programar es escribir instrucciones precisas para que una
computadora resuelva un problema. Un programa es una secuencia de
instrucciones escritas en un lenguaje de programación.

Pasos para resolver un problema:
  1. Entender el problema (entradas, salidas, restricciones).
  2. Diseñar un algoritmo (pseudocódigo, diagramas).
  3. Implementarlo en un lenguaje.
  4. Probar y depurar.
  5. Mejorar y documentar.

Algoritmo: conjunto finito, ordenado y no ambiguo de pasos para
resolver un problema. Ejemplo (promedio de dos números): leer a,
leer b, calcular (a + b)/2, mostrar el resultado.


##############################################################
2. CÓMO FUNCIONA UNA COMPUTADORA
##############################################################
  Hardware: CPU (ejecuta instrucciones), RAM (memoria temporal),
  almacenamiento (SSD/HDD), GPU, placa madre, periféricos.
  Software: sistema operativo, aplicaciones, controladores.
  Binario: todo se representa con bits (0 y 1). 8 bits = 1 byte.
  1 KB ≈ 1000 bytes (1 KiB = 1024). Texto se codifica con ASCII y
  Unicode (UTF-8); imágenes como píxeles; sonido como muestras.
  Lógica digital: puertas AND, OR, NOT, XOR; circuitos con
  transistores.
  Código fuente -> compilador/intérprete -> instrucciones de
  máquina.
  Compilado (C, C++, Rust, Go): se traduce antes de ejecutar; rápido.
  Interpretado (Python, JavaScript): se ejecuta línea a línea (o por
  bytecode/JIT); flexible.
  Memoria: pila (stack) para llamadas y variables locales; montón
  (heap) para memoria dinámica; recolección de basura o gestión
  manual.

4. CONTROL DE FLUJO
##############################################################
4.1 Condicionales
-----------------
    nota = 7.5
    if nota >= 9:
        print("Excelente")

4.2 Bucles
----------
    for i in range(5):        # 0,1,2,3,4

    contador = 0

        print(contador)
        contador += 1

  bucles infinitos.

4.3 Ejemplo: tabla de multiplicar
---------------------------------
    n = 7
    for i in range(1, 11):
        print(f"{n} x {i} = {n * i}")

4.4 Ejemplo: FizzBuzz
---------------------
    for i in range(1, 101):
        if i % 15 == 0: print("FizzBuzz")
        elif i % 3 == 0: print("Fizz")
        elif i % 5 == 0: print("Buzz")
        else: print(i)

5. FUNCIONES
##############################################################
    def area_circulo(radio):
        return 3.14159 * radio ** 2

    print(area_circulo(5))

  Parámetros, argumentos, valor de retorno, valores por defecto,
  argumentos con nombre, *args y **kwargs.
  Alcance (scope): variables locales vs globales.
  Funciones puras: sin efectos secundarios.
  Recursión: una función que se llama a sí misma.

    def factorial(n):
        if n <= 1:          # caso base
            return 1
        return n * factorial(n - 1)

  Funciones lambda: lambda x: x * 2.
  Principio: una función, una responsabilidad.

6. ESTRUCTURAS DE DATOS
##############################################################
6.1 En Python
-------------
    lista = [3, 1, 2]           # mutable, ordenada
    lista.append(4); lista.sort()
    tupla = (1, 2)               # inmutable
    conjunto = {1, 2, 3}         # sin duplicados
    dic = {"nombre": "Ana", "edad": 25}   # clave-valor
    dic["edad"]

    [x**2 for x in range(5)]     # comprensión de listas

6.2 Estructuras clásicas
------------------------
  Arreglo: acceso por índice O(1).
  Lista enlazada: inserción/eliminación eficientes, acceso O(n).
  Pila (stack, LIFO): push/pop. Uso: deshacer, llamadas a funciones.
  Cola (queue, FIFO): enqueue/dequeue. Uso: tareas, BFS.
  Tabla hash / diccionario: búsqueda promedio O(1); colisiones.
  Árbol binario de búsqueda: búsqueda O(log n) si balanceado (AVL,
  rojo-negro). Heap (cola de prioridad). Trie (prefijos).
  Grafo: vértices y aristas; matriz o lista de adyacencia.
  Recorridos de grafos y árboles: DFS (profundidad), BFS (anchura).


##############################################################
7. ALGORITMOS Y COMPLEJIDAD
##############################################################
7.1 Notación Big O
------------------
  O(1) constante; O(log n) logarítmica; O(n) lineal; O(n log n);
  O(n^2) cuadrática; O(2^n) exponencial; O(n!) factorial.
  Describe cómo crece el tiempo (o la memoria) al aumentar n.
  Mejor caso, caso promedio y peor caso.

7.2 Ordenamiento
----------------
  Burbuja, selección, inserción: O(n^2).
  Mergesort: O(n log n), estable, divide y vencerás.
  Quicksort: promedio O(n log n), peor O(n^2).
  Heapsort: O(n log n). Counting/radix: lineal bajo ciertas
  condiciones.

7.3 Búsqueda
------------
    def busqueda_binaria(lista, objetivo):
        izq, der = 0, len(lista) - 1
        while izq <= der:
            medio = (izq + der) // 2
            if lista[medio] == objetivo:
                return medio
            elif lista[medio] < objetivo:
                izq = medio + 1
            else:
                der = medio - 1
        return -1          # O(log n), requiere lista ordenada

7.4 Técnicas de diseño
----------------------
  Fuerza bruta, divide y vencerás, voraz (greedy), programación
  dinámica, backtracking, ramificación y poda.
  Programación dinámica (Fibonacci con memoización):

    from functools import lru_cache
    @lru_cache(None)
    def fib(n):
        return n if n < 2 else fib(n-1) + fib(n-2)

  Algoritmos de grafos: Dijkstra (camino mínimo), A*, Kruskal y
  Prim (árbol de expansión mínima), ordenamiento topológico.
  Teoría de la computación: clases P, NP, NP-completo; problema
  del viajante; indecidibilidad (problema de la parada).


##############################################################
8. PROGRAMACIÓN ORIENTADA A OBJETOS (POO)
##############################################################
  Clase: plantilla. Objeto: instancia. Atributos y métodos.

    class Animal:
        def __init__(self, nombre):
            self.nombre = nombre
        def hablar(self):
            raise NotImplementedError

    class Perro(Animal):
        def hablar(self):
            return f"{self.nombre} dice guau"

    print(Perro("Rex").hablar())

  Pilares: encapsulamiento, abstracción, herencia, polimorfismo.
  Composición sobre herencia (cuando sea posible).
  Principios SOLID:
    S: una sola responsabilidad.
    O: abierto a extensión, cerrado a modificación.
    L: sustitución de Liskov.
    I: segregación de interfaces.
    D: inversión de dependencias.
  Patrones de diseño: Singleton, Factory, Builder, Adapter,
  Decorator, Observer, Strategy, MVC.

9. PROGRAMACIÓN FUNCIONAL Y OTROS PARADIGMAS
##############################################################
  Funcional: funciones como valores, inmutabilidad, map/filter/

  Imperativo/procedural, declarativo (SQL, HTML), lógico (Prolog),
  orientado a eventos, reactivo.
  Programación genérica y metaprogramación.
  Corrutinas y async/await.


##############################################################
10. ERRORES, PRUEBAS Y DEPURACIÓN
##############################################################
  Tipos de error: sintaxis, ejecución (runtime), lógicos.
  Excepciones:
    try:
        x = int(input())
    except ValueError:
        print("No es un número")
    finally:
        print("Fin")
  Depuración: leer el mensaje de error, reproducir el fallo,
  aislar, imprimir/loggear valores, usar un depurador (breakpoints),
  "rubber duck debugging".
  Pruebas: unitarias (pytest, JUnit, Jest), integración,
  end-to-end, TDD (escribir la prueba primero), cobertura.
  Logging, linters, formateadores, análisis estático.

12. BASES DE DATOS
##############################################################
  Relacionales (SQL): PostgreSQL, MySQL, SQLite.
    SELECT nombre, edad FROM usuarios WHERE edad > 18 ORDER BY nombre;
    INSERT INTO usuarios (nombre, edad) VALUES ('Ana', 25);
    UPDATE usuarios SET edad = 26 WHERE nombre = 'Ana';

    JOIN: unir tablas (INNER, LEFT, RIGHT).
    GROUP BY, HAVING, agregaciones (COUNT, SUM, AVG).
  Conceptos: claves primarias y foráneas, índices, normalización
  (1FN, 2FN, 3FN), transacciones y propiedades ACID, concurrencia.

  ORMs, migraciones, almacenes de datos y data lakes.

##############################################################
16. SEGURIDAD
##############################################################
  Principios: confidencialidad, integridad, disponibilidad.
  Criptografía: simétrica (AES), asimétrica (RSA, curvas
  elípticas), funciones hash (SHA-256), firmas digitales,
  certificados.
  Contraseñas: nunca se guardan en texto plano; usar hash con sal
  (bcrypt, argon2). Autenticación multifactor.
  Vulnerabilidades comunes (OWASP Top 10): inyección SQL, XSS,
  CSRF, autenticación rota, configuración insegura, exposición de
  datos.
  Prácticas: validar entradas, consultas parametrizadas, principio
  de mínimo privilegio, actualizar dependencias, no subir secretos
  a repositorios.
  Privacidad y protección de datos.

19. RUTA DE APRENDIZAJE Y BUENAS PRÁCTICAS
##############################################################
  Ruta sugerida:
    1) Lógica y un primer lenguaje (Python).
    2) Estructuras de datos y algoritmos básicos.
    3) Git y línea de comandos.
    4) Proyectos pequeños (calculadora, lista de tareas, juego,
       scraper).

    6) Web (HTML/CSS/JS + un backend) o datos, según interés.
    7) Bases de datos, APIs, despliegue.
    8) Proyectos propios y contribución a código abierto.
  Buenas prácticas: escribe código legible, nombra bien, divide
  problemas, prueba, comenta el porqué (no el qué), refactoriza,
  lee código ajeno, aprende a leer documentación, y practica
  resolviendo problemas (Project Euler, LeetCode, Advent of Code).
  Aprende a buscar errores en la documentación y a depurar:
  es el 50 % del trabajo.
